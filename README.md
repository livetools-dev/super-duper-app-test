# Super Duper App Test

Helps answer workholding challenges for prospects, starting with one shop's problem: gripping small parts on a big lathe with a 21 inch hydraulic chuck and a 160 mm bore, by comparing extended jaws, a smaller chuck and a collet chuck.

This is a small Livetools app built with the Livetools design system and published on GitHub Pages. Everything, from installing to building screens to publishing, is done by the AI from inside the repository.
